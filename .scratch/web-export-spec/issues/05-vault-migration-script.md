# 05: 舊對話檔轉換工具

**What to build:** 一個本機腳本，把舊版網頁匯出檔（COM／COMBINED／API／DOM）轉成規範 §3 的格式與 §5 的檔名，讓使用者自行對 MainVault 執行。內容轉換：移除舊檔頭的「匯出來源／核對結果／擷取方式」、注意清單與相對時間提醒（確定不完整的項目改成 `> **不完整**：…`）；收集逐則 `API 時間`／`時間：` 行，改為檔頭時間範圍後刪除；多行 JSON 補充資料改寫成單行；舊佔位字換成新字表；GEM 檔移除程式碼外的 `[cite: N]`；「來源衝突」與單邊標記改成新用語。
